# Framework Explorer

See how five web design toolkits (Bootstrap, Tailwind, Bulma, Materialize, Foundation) look, and try new designs with your AI coding agent.

## First-time setup

New to this? Follow the step-by-step **[setup guide for Windows](docs/setup.md)**. It shows how to open PowerShell, install everything, download the project and start your AI agent. Every command has a copy button.

## Getting started

1. Double-click **`index.html`** to open it in your web browser. You need to be online.
2. Click any framework card. It opens in a new tab.
3. Scroll through the page. Every framework shows the same pretend property inspection website, so you can compare them fairly. The **Layout & Containers** section shows lots of ways to lay out content: cards, grids, lists, accordions and more.
4. Click the round **🎨** button at the bottom-left of any framework page to change the fonts, colours and borders. Your choices are saved in your browser; **Reset all** puts the page back. **Copy my choices** gives you a message to paste to your AI agent so it can build that look into a new page.
5. At the bottom of each page, copy a prompt and paste it into your AI agent (for example Claude Code, opened in this folder).
6. Go back to the home page and refresh it. New designs show up under **My experiments**.

## Tips for talking to your AI

- Use the grey labels on each page to name things: *"make the horizontal card bigger"*, *"put the accordion next to the sidebar"*.
- Be specific about feelings: *"more trustworthy"*, *"less cluttered"*, *"friendlier"*.
- Ask for options: *"show me three versions"*.
- Your AI always makes a **copy**, so the originals never break and you can always go back.
